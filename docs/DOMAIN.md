# Как устроена медстраховка в США

Короткая шпаргалка для команды и для ответов жюри.

## Главное

В США у работающих людей нет единого государственного фонда вроде ОСМС. Страховку продают частные компании, обычно через работодателя. Ближайшая аналогия — КАСКО с франшизой: платишь каждый месяц, а при обращении сначала платишь сам.

Раз в год, обычно в ноябре, работодатель даёт выбрать один из 2–4 планов. Этот период называется **open enrollment**. Выбор действует весь год.

## Термины

| Термин | Что это |
| --- | --- |
| Premium, взнос | Ежемесячная плата за страховку. Большую часть платит работодатель, долю работника удерживают из зарплаты |
| Deductible, франшиза | Сумма в год, которую пациент платит сам полностью, прежде чем страховая начнёт платить |
| Copay | Фиксированная плата за визит, например $25 за терапевта |
| Coinsurance | Процент, который пациент платит после франшизы, обычно 20% |
| Out-of-pocket maximum | Потолок расходов пациента за год. Выше него страховая платит всё |
| Network, сеть | Врачи и больницы, с которыми у плана договор. Вне сети цены и лимиты не действуют |
| SBC | Summary of Benefits and Coverage. Стандартный федеральный документ на несколько страниц с условиями плана. Одинаковая форма у всех планов |
| HDHP | План с высокой франшизой и дешёвым взносом |
| PPO, HMO | Типы планов. PPO дороже и свободнее в выборе врачей. В HMO к специалисту нужно направление |
| HSA | Личный счёт для медицинских расходов, деньги идут туда до налогов. Доступен только с HDHP. Работодатель иногда кладёт туда свои деньги |
| Tier, уровень покрытия | Кого страхует план: только работника, работника с супругом, с детьми или всю семью. У каждого уровня свой взнос |
| Embedded deductible | На семейном плане один человек не платит больше личной франшизы. Если франшиза не embedded, семья должна набрать всю семейную сумму |
| Spousal surcharge | Доплата, если супруга добавляют в план, хотя у него есть страховка от своего работодателя |
| EOB | Explanation of Benefits. Расчёт от страховой после визита: сколько стоила услуга и сколько должен пациент |

## В чём боль

Суть выбора всегда одна: дешёвый взнос и высокая франшиза или дорогой взнос и низкая франшиза. Правильный ответ зависит от того, сколько семья будет лечиться, а это надо прикинуть на год вперёд и посчитать для каждого плана.

Если работают оба супруга, у семьи два набора планов и несколько способов распределиться: все на его плане, все на её, каждый на своём, дети с одним из них. Инструменты работодателей показывают только планы своей компании, поэтому сравнить всё вместе человеку негде.

## Цифры для питча

- 154 млн человек до 65 лет застрахованы через работодателя (KFF, отчёт 2025).
- Семейный план в 2026 году стоит в среднем $28 303 в год, работник платит из них $7 471, на 9% больше, чем год назад (KFF, октябрь 2026).
- В исследовании на 23 894 сотрудниках большинство выбрало план, который проигрывал другому доступному плану (Bhargava, Loewenstein, Sydnor, QJE 2017).
- 41% взрослых имели долг за медицину, около 100 млн человек (KFF, опрос 2022 года).
