Инструмент: Claude Code. Ты капитан: держишь расчётное ядро, главный экран продукта, интеграцию и выступление.

## Твои файлы

`src/app/page.tsx`, `src/app/profile/**`, `src/app/result/**`, `src/components/profile/**`, `src/components/result/**`, `src/lib/calc/**`

## Задачи по порядку

### 1. Экран `/result`

- Читает `loadSession()`, вызывает `recommend(household, plans, REFERENCE_PRICES)`.
- Показывает лучший вариант, сумму экономии, цену для хорошего, обычного и плохого года, потолок расходов.
- Показывает все варианты списком, предупреждения по каждому и список допущений.
- Пустое состояние, если планов или профиля нет: ссылка на нужный шаг.

### 2. Анкета `/profile`

- Собирает `Household`: состав семьи, ожидаемое лечение по каждому человеку, накопления на непредвиденный счёт, нужные услуги, врачи, которых нельзя терять.
- Вопросы ветвятся: ответ открывает уточнения.
- Пропущенный вопрос сохраняется как допущение со значением по умолчанию и пояснением.

### 3. Уточняющие вопросы по влиянию на результат

Для каждого допущения пересчитать вердикт с минимальным и максимальным значением. Если победитель меняется, задать вопрос пользователю. Логика живёт в `src/lib/calc` и покрыта тестами.

### 4. Лендинг и пример

- Лендинг объясняет продукт за пять секунд и ведёт на `/start`.
- Кнопка «попробовать на примере» загружает реальные SBC из `public/samples` через тот же `/api/extract`.

### 5. Интеграция

Следишь, чтобы поток `/start` → `/profile` → `/result` работал на продакшене, и сливаешь ветки.

### 6. Питч

Текст на 5 минут на русском, ответы на вероятные вопросы жюри, три репетиции с таймером. Шпаргалка по теме лежит в `docs/DOMAIN.md`.
